## Current focus

- **Robot platform**: ROS2, arm control with ros2_control and MoveIt, MuJoCo simulation
- **Imitation learning**: teleoperated data collection, LeRobot and GR00T training and inference on real robots
- **Parts in code**: 3D-printed robot parts modeled with manifold3d and build123d, printed on a Bambu Lab P2S
